# 학습 기록 관리

사용자는 gstack 구조에 담긴 판단 기준을 질문과 답으로 확인하고 있다. 목적은 분석·설계·구현 문서 관리 체계를 직접 설계하는 것이다. 이 작업의 기록은 gstack-fork 저장소(/home/user/gstack-fork)의 `study-notes/doc-management/` 폴더에 있다.

- 이 작업을 이어 갈 때는 그 폴더의 README.md를 먼저 읽는다. README에는 사용자 상황, 기록 방식, 목차, 결정 현황이 있다.
- 진행 방식은 사용자의 질문이 중심이다. 다음 주제를 정할 때는 사용자가 겪을 만한 상황을 예시로 몇 가지 제안하고, 사용자가 고르거나 직접 질문하게 한다.
- 질문에 답한 뒤에는 결론을 주제 파일에 기록한다. 같은 주제의 후속 질문은 기존 파일에 덧붙이고, 새 주제는 새 파일을 만든다. 파일 하나에 모든 기록을 쌓지 않는다.
- 파일 하나가 200줄을 넘거나 두 주제를 다루게 되면 나눈다.
- README에는 목차와 결정 현황만 둔다. 새 주제 파일을 만들면 목차에, 새 결정이 생기거나 바뀌면 결정 현황에 반영한다.
- 기록에는 결론, 근거(gstack의 어느 파일에 무엇이 있는지), 사용자 상황에 적용할 때의 판단을 쓴다. 대화 과정은 쓰지 않는다.
- 기록을 바꾸면 gstack-fork의 작업 브랜치 `ccr-41eebff6-9wtyzm`에 커밋하고 push한다.
